# The Last Forge

A complete top-down action roguelite built in Godot 4.7, from an empty project to an exported game, in
the free Godot 4 roguelike course on the [CodingQuests YouTube channel](https://www.youtube.com/@CodingQuests).

Dashing combat with invincibility frames, five enemy types and a boss with a warning tell, random floors of
connected rooms, items that combine into builds, corruption that trades power for fragility, shops and a gambling
altar, a death screen and permanent unlocks at the Forge, a title screen, sound, and an export.

**This branch (`main`) is the finished game.** Every lesson of the course has its own branch with the project as it
stands at the end of that lesson.

2. Click **ZIP**, unzip it, and open `project.godot` in Godot 4.7.2.
3. Follow the lesson from there. If your game does something different from the video, download that lesson's

## Build it yourself, in the browser

The whole course is also seven interactive quests on CodingQuests. Same game, same node names, but you write each
system yourself and it checks your code. The Top-Down Controller quest is free, no account needed:
https://codingquests.io/roguelike?utm_source=github&utm_medium=readme&utm_campaign=fcc_2d_roguelike&utm_content=readme

## Requirements

[Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/), the standard version (not .NET). Anything from 4.6 on should open it.
Controls: WASD move · Z dash · left mouse quick attack · right mouse heavy attack · E item · F interact ·
Q swap weapon · Tab codex.
